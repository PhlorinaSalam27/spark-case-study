# Apache Spark Case Study Using PySpark

## Overview
This project demonstrates Apache Spark programming using PySpark. It contains examples of matrix operations, Spark SQL queries, and Spark Streaming concepts.

## Technologies Used
- Python
- Apache Spark
- PySpark
- Spark SQL
- Structured Streaming

## Project Files

### 1. matrix_operations.py
Demonstrates matrix-related operations using PySpark.

### 2. spark_sql.py
Demonstrates data processing and SQL queries using Spark SQL.

### 3. spark_streaming.py
Demonstrates streaming data processing concepts using Spark.

## How to Run

1. Install Python and Java, and configure the required environment variables.
2. Install PySpark:

   ```bash
   pip install pyspark
   ```

3. Navigate to the project directory.
4. Run a program:

   ```bash
   python matrix_operations.py
   ```

   You can similarly run `spark_sql.py` and `spark_streaming.py`.

## Purpose
The purpose of this project is to understand distributed data processing and explore Apache Spark's capabilities for data analytics.
